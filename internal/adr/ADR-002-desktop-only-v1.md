# ADR-002 — Desktop-Only V1

**Status:** Accepted | **Date:** 2026-09-20

## Context

Quantitative research, local worker processes, and substantial datasets need a
reliable desktop environment.

## Decision

V1 targets Obsidian Desktop only.

## Alternatives considered

Mobile-compatible architecture from the outset.

## Consequences

No mobile compromises are imposed; a later read-only mobile experience is a new
decision.
