# ADR-008 — Architecture Spike Before Product Development

**Status:** Accepted | **Date:** 2026-09-20

## Context

The new plugin/worker/Parquet/vault architecture has material integration risk.

## Decision

Validate a narrow end-to-end vertical slice in Milestone 0 before broader work.

## Alternatives considered

Building product domains immediately; validating components independently only.

## Consequences

Failure criteria can change architecture early; broader implementation is paused.
