# Internal Development Material

Everything under `internal/` is private, development-only project material.

It may contain architecture records, agent handoffs, development playbooks,
engineering journals, and external-reference records. It is **not** part of any
future Free or Pro product release and must not be bundled in product artifacts.
Release tooling must use an explicit allowlist and reject this directory.

Product-facing material belongs only in `product-docs/` after it has been
written and reviewed for distribution.
