# External Reference Repositories Framework

**Date:** 2026-09-20  
**Scope:** private documentation and project boundaries only.

## Change

Created `internal/references/` with a standing external-reference code policy,
a compact register, and separate notes for Journalit and Strategy Factory.

## Boundary

The repositories remain reference-only. No repository was cloned, inspected for
source code, copied into the project, added as a dependency, or added to
`THIRD_PARTY_LICENSES.md`.

## Standing rule added to agent guidance

Conceptual learning and independent pattern implementation are allowed. Any
actual source or asset reuse requires work to stop first, with the exact
repository, commit, file/module/function, and intended use identified for the
project owner to obtain rights-holder permission or suitable licensing.

## Manual review required

The project owner should review the reference register before authorising a
local clone. If a clone is later requested, confirm the desired repository and
record the exact resulting commit hash before any substantive inspection.
