# Lessons Learned

## LL-001 — Define the metric before calculating it

Daily drawdown has no universal meaning. Record its baseline, reset schedule/timezone, and realised/floating treatment with every result.

## LL-002 — Verify underlying state, not indirect signals

For setup and research calculations, inspect the actual path, raw input, domain log, and expected artifact rather than trusting defaults, UI summaries, or a process exit code alone.
