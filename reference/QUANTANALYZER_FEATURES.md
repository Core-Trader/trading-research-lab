# QuantAnalyzer Reference Notes

## Purpose

This is a research-notes placeholder, not a feature inventory or a claim of compatibility. It records the product areas worth studying when the owner supplies verified product documentation, screenshots, exports, or a licence-permitted evaluation.

## Study questions

- Which report metrics are useful to traders, and what precise formulas/assumptions do they use?
- How are trade lists, equity curves, drawdown, Monte Carlo, and portfolio results represented and exported?
- Which UI patterns make an adverse period traceable to trades/events?
- Which results depend on imported balance data versus reconstructed equity/margin assumptions?

## Adoption rule

Trading Research Lab will define its own calculation policies, data provenance, and UI. A familiar metric name does not authorize copying a formula, interface, data format, or proprietary behavior. Add verified citations and licence considerations before treating any external behavior as a requirement.

## Current implication

The product should make metric definitions and underlying event evidence more explicit than a summary-only report. No direct integration is in scope.
